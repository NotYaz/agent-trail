Which agent touched this project last?

Agent Trail is a native macOS menu-bar app that puts your coding projects and live Claude, Codex, and Grok sessions in one panel. See recorded edits and trends, who is working or waiting, and jump back to the session.

Since 0.1.0-alpha.9 · For training runs and other long jobs

The turn ended. The training run didn’t.

Start a training run, a long build, or a loop that waits on a job, and let Claude’s turn end. Agent Trail keeps that session Working and labels it Working in background until the command exits, instead of calling it Idle.

What you see

Menus, Jump entries, and the card tooltip say Working in background. The tooltip names when the command started:

Claude · Main finished its turn, but a command it started at 2:14 PM is still running in the background.

The menu-bar dot keeps moving while the job runs. When the command exits the session goes Idle, and if nothing else is working or waiting, the icon shows a checkmark for a few seconds.

How it knows

Claude runs each Bash command in its own process group, while MCP servers stay in Claude’s. Agent Trail lists the session process’s children and counts only those that lead their own group and started before the turn ended.

  • Claude session process
  • MCP serverstays in Claude’s groupignored
  • Bash commandown group, started during the turncounts
  • Hookstarted after the turn endedignored

What it reads, and the limits

Only each child’s parent, process group, and start time, through libproc. No arguments, no environment, and no extra processes started.

  • A command that never exits keeps its session Working until it ends or the session closes.
  • A job that fully detaches, with no command still waiting on it, cannot be tied to a session. Keep a command waiting on it, such as a loop that polls for the job to finish.
  • Claude sessions only. Codex and Grok status is unchanged.
  • AgentTrailInspect --live reports backgroundSince.

What’s in the panel

Every project once. Every agent on it.

Two assistants, the same repository, different worktrees and conversations. Agent Trail brings recorded history and reported live status together on one card per project, so getting back to work starts with the right window.

One card per project, live status on each

A project is the Git checkout where an assistant’s confirmed edits actually landed. Claude, Codex, and Grok working in the same repository share one card, even when they were started in different folders, and the card shows what each of them is doing now.

  • A 30-day sparkline, recorded edits with the change from the previous 30 days, and a profile mix bar.
  • The Pulse strip: live sessions, edits in the last 7 days, active projects, and your day streak.
  • Search, Needs input and Working filters, Shared projects, and sorting by edits, trend, or name.
  • Move a repository and its history follows. Earlier locations are remembered.
Needs inputClaude asked, or Grok has a permission request

Each card counts its sessions in every state, in total and by profile. Projects needing input sort first, then working ones.

Jump back to the session

Each card’s main button opens the session that most needs you, with its profile, title, and time in that state. The ⌄ menu lists every live session and opens the worktree in your editor, terminal, or Finder.

From any app, press ⌃⌥J for a switcher with every live session, needs input first. Type to filter, then press Return or ⌘1–⌘9. An agenttrail://jump link opens the most urgent session from Shortcuts, Raycast, or a shell.

  • Claude Code sessions open through Claude’s session link. With several Claude instances, macOS gives that link only to the one launched first, so another instance’s sessions bring that instance forward with a hint naming the session.
  • claude in a terminal brings that terminal forward, or the Claude window whose terminal pane runs it.
  • Codex threads open through codex://threads when the Codex app owns them.
  • Grok brings forward the terminal it runs in.

Agent Trail acts only when you click, press the switcher’s shortcut, or open a link, and only on apps already running. It never launches, quits, or restarts an assistant, and needs no Automation or Accessibility permission.

A menu-bar icon that tells you

See the state without opening anything. Right-click the icon for live sessions grouped by state, and pick one to jump to it.

Animation runs in Core Animation and stops for Reduce Motion, Low Power Mode, and sleeping displays.

  • Plain trailNothing is working or waiting.
  • A dot travels the trailAt least one session is working.
  • 2 Amber, with a countA session needs input.
  • CheckmarkWork just finished and nothing else runs.

Growth statistics

Recorded edits per day with a 7-day average and peak, a 26-week Trail calendar, when your edits land by hour and weekday, each profile’s share with delegated edits, and where edits landed.

  • Local activity days start at 05:00, so late-night work counts toward the evening it began.
  • Changes are shown only when saved history covers the previous period.
  • Counts are confirmed tool edits, not lines of code, quality, or productivity.

The Map: branches, sessions, and merges

A third tab (⌘3) draws one project’s Git branches, the sessions that edited each one, and where they merged, on a timeline with idle hours folded away. Switch between Lanes, Tree, Orbit, and Log, for today, 7 or 30 days, or all saved history.

  • An edit counts for the branch of the next commit in its working tree within 12 hours, so work done before checkout -b lands on the new branch. A checkout of an existing branch or a reset before that commit leaves it on the branch it was made on.
  • Merge commits and squashed pull requests are matched to their branches. Claude worktrees map to their branches even after they are removed, and cloud sessions on claude.ai show through their commits.
  • In Lanes, a workflow’s agents, or three or more branches worked on side by side, share one row as strands that open on click.
  • Open it in a resizable window for a wider timeline and a details panel for what you hover or click.

The Map reads Git only while it is on screen, with the git from Xcode, the Command Line Tools, or Homebrew, and never changes the repository. Author names and e-mail addresses are not kept.

An activity portrait to share

Preview a card for any project and period, then export a PNG to your Mac. Project and profile names are hidden by default. Folder paths and your hour-of-day rhythm are never included, and nothing is posted or uploaded.

Privacy

Everything stays on your Mac.

No account, no telemetry, no cloud, and no automatic update checks. Agent Trail indexes locally and sends your records nowhere.

Read-only

It reads the assistants’ private on-disk formats and never writes them. No hooks, no injected code, and no edits to assistant data. Codex turn metadata is opened read-only, and the Map runs git read-only with network access turned off.

Titles in memory only

Session titles and Claude’s “needs you to…” sentence are read live and kept in memory. They are never cached, exported, or included in renders.

Caches without content

Incremental caches keep file positions, tool IDs, dates, and paths. Never prompts, commands, patches, diffs, or conversation text. Paths can still be sensitive, so keep them private.

Exports you control

Portraits are saved where you choose, with names hidden by default and folder paths never included. Dates, totals, and patterns stay visible, so review a card before sharing it.

Install

Build it yourself, or grab the alpha.

Agent Trail needs macOS 14 or later. It has no third-party dependencies and no developer account is required to build it.

Build from source

A local build opens without the first-launch warning. Needs Swift 6 or later, from Xcode or the Command Line Tools.

git clone https://github.com/NotYaz/agent-trail.git
cd agent-trail
swift test
./scripts/build-app.sh
open "dist/Agent Trail.app"

The panel opens right away and a trail icon stays in the menu bar, with no Dock icon. To install, copy dist/Agent Trail.app to Applications.

Download the alpha

0.1.0-alpha.13

A universal ZIP for Apple Silicon and Intel Macs, with a SHA-256 checksum.

Builds are ad-hoc signed and not notarized, so macOS stops the first launch. Close the warning, then choose Open Anyway in System Settings › Privacy & Security and enter your login password. All steps.
