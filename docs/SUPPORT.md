Each QR code holds only the address. The canonical list is this page in the [NotYaz/agent-trail](https://github.com/NotYaz/agent-trail/blob/main/docs/SUPPORT.md#crypto) repository on GitHub; forks and copies can show different addresses. Before sending, compare the whole address your wallet shows with the text on that page, not only its first and last characters, which look-alike scam addresses imitate. Treat an address you receive in a message with suspicion.

## Other ways to help

You can also help by [reporting a reproducible issue](https://github.com/NotYaz/agent-trail/issues), improving compatibility fixtures, or contributing an assistant adapter. Use synthetic records when sharing examples; see [CONTRIBUTING.md](../CONTRIBUTING.md).

Agent Trail does not process payments or need access to a wallet.
