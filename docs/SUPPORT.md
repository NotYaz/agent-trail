# Support Agent Trail

Agent Trail is free and open source under the [MIT license](../LICENSE). Support is optional; all features stay available without payment.

**Donations are not configured for this alpha.** There are no official receiving addresses, payment links, or wallet connections yet. This page will be updated when the maintainer publishes the selected public receiving addresses and exact networks.

You can help now by [reporting a reproducible issue](https://github.com/NotYaz/agent-trail/issues), improving compatibility fixtures, or contributing an assistant adapter. Use synthetic records when sharing examples; see [CONTRIBUTING.md](../CONTRIBUTING.md).

## Adding direct crypto donations later

The maintainer can add a small table here with the asset, exact blockchain network, public receiving address, and a matching QR code. Verify each published address on the receiving wallet. Keep private keys and recovery phrases out of the repository.

After addresses are configured, `.github/FUNDING.yml` can point GitHub's sponsor button to this page:

```yaml
custom: ["https://github.com/NotYaz/agent-trail/blob/main/docs/SUPPORT.md"]
```

Agent Trail itself does not process payments or need access to a wallet.
